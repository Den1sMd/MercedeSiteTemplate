# Mercedes Website Template

Bienvenue dans le projet **Mercedes Website Template**, un site vitrine pour présenter des modèles Mercedes, réserver des rendez-vous et découvrir les avantages exclusifs de la marque.

---

## 🚀 Fonctionnalités principales

- **Page d'accueil dynamique** avec vidéo de présentation et slogan « Rejoindre Mercedes c'est rejoindre une famille ! ».
- **Présentation des modèles tendances** :  
  - Mercedes C63 AMG  
  - Mercedes GLC  
  - Mercedes Classe GLE  
  Chaque modèle affiche ses caractéristiques : kilométrage, carburant, année, prix, et un bouton "En savoir plus".
- **Section rendez-vous** pour réserver chez le concessionnaire.
- **Avantages Mercedes** pour les utilisateurs :  
  - Services premium  
  - Offres exclusives et programme de fidélité  
  - Promotions sur les contrôles techniques
- **Section communauté** : Rejoignez plus de 100 000 utilisateurs à travers le monde.
- **Intégration des réseaux sociaux** : Instagram, LinkedIn, Twitter et YouTube.
- **Footer complet** : liens rapides, adresse du concessionnaire, crédits et copyright.

---

## 🛠️ Technologies utilisées

- [Next.js](https://nextjs.org/) - Framework React pour les applications web.
- [React](https://reactjs.org/) - Bibliothèque JavaScript pour l'interface utilisateur.
- [Tailwind CSS](https://tailwindcss.com/) - Framework CSS pour le design.
- [Framer Motion](https://www.framer.com/motion/) - Pour les animations.
- [Lucide Icons](https://lucide.dev/) - Icônes vectorielles.

---

## 📂 Structure du projet

- `pages/` : Contient toutes les pages du site (`index.js`, `contact.js`, `information.js`, etc.).
- `components/` : Composants réutilisables (boutons, cartes modèles, etc.).
- `public/` : Images et vidéos utilisées sur le site.
- `styles/` : Fichiers CSS et Tailwind.
